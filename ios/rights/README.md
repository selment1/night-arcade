# 配布へ向けた権利対応

状態: **未クリア。申請可能・非侵害の保証ではない。**

現行ゲーム・セーブ・iOS開発用素材は変更していない。配布用の素材候補を分けて準備した。現行の40マス／価格・賃料／色組／角の組合せは独自化か許諾の対象として残る。単に名前と画像を変えて完了とはしない。

## 実施したこと

- `prepare-original-art.py` により、開発用素材から別の配布検討用素材セット `ios/build/original-art/Web` を生成。
- 外部写真22点を候補から除去。独自のSVG図案22点に差し替え。「現地写真ではありません」と明記し、世界遺産の再現図を装わない。元写真の作者表示を勝手に自作表示へ変えておらず、画像そのものを別の図案へ交換している。
- 素材ごとの生成元とSHA-256を `ART-PROVENANCE.json` に記録。元の写真付き開発版・公開Web版は残した。
- 320/390pxで全22枚のデコード、説明文、非写真表示、CPU開始、横はみ出し・JSエラーなしを検証。
- `clearance.json` と `check-rights.py` を作成。現状はexit2で未完了項目を表示する。この補助チェックはXcodeやAppleの審査を代行／強制するものではない。

```sh
python3 ios/scripts/prepare-original-art.py
node ios/scripts/verify-original-art.mjs
python3 ios/scripts/check-rights.py
```

図案セットも同じルール・盤面を含むため、そのまま出品してよい完成品ではない。現行のXcodeプロジェクトは引き続き写真付き開発版を使う。候補への切り替えは独自ルールと保存互換性を検証してから行う。

## 次の実装案：独自ゲーム化

世界遺産、€、正方形の見渡せる盤面、CPU1〜3人、通信、交渉、出目・入出金の演出は維持する。一方で、原作品に近い特徴の組合せは置き換える。

- 32マス、均等な角、非対称なイベント配置。22物件・4交通・2公共施設・8色の構成は使わない。
- 土地自体の所有ではなく、旅行の案内・文化交流拠点への出資として明確化。世界遺産を実際に建て替える表現を避ける。
- 16拠点・4路線・8旅程イベント・4休息/出発マスを候補とする。数値は独立した経済モデルで設計・シミュレーションする。
- 12ラウンドの旅行を基本に、訪問記録・文化交流・資産の複合スコアで決着する。破産まで延々と続ける構成から変える。
- 拘留所・脱出カード・3回ゾロ目処理は使わない。旅程の遅延・休息として別の選択とコストを設計する。
- カード文章・図柄・色体系を新規作成。競売/交渉は一般的仕組みとして残すが、参加方法と決済は新ルールに合わせて設計する。
- 別ルール版は保存キー・通信ルームの識別子を分離。旧対戦へ新しい金額やマス配置を読み込まず、旧版は引き続き再開できるようにする。

純粋ルールの最小候補を別フォルダーの [candidate/RULES.md](candidate/RULES.md) に実装した。32マス・12ラウンド・訪問/文化交流/資産の採点を検証できるが、UI・CPU・通信・保存・競売・交渉は未実装で、公開版やiOSバンドルには接続していない。32マス版の完成を意味しない。検証は `node --test ios/rights/candidate/engine.test.mjs`。ユーザーの方向指定が入れば反映する。独自化しても正式名称・図形の商標調査や確定配布物のレビューは必要。

## 公式許諾を選ぶ場合

Hasbroの一般FAQは無許諾のカスタマイズを認めていない。したがってFAQを許可証と扱わず、デジタルゲーム、対象国、商用配信、改変可能範囲を含む書面の契約が必要。問い合わせ先/権限を確認したうえで、費用と契約内容をユーザーが判断できる資料を作る。現在は問い合わせ・契約・支払いを行っていない。

[Hasbro公式FAQ](https://hasbro-new.custhelp.com/app/answers/detail_uk/a_id/9/kw/resell%20products) は権利者の立場の説明であり、裁判所による本アプリの判断ではない。[米著作権局](https://www.copyright.gov/register/tx-games.html) は方法と説明文・美術を区別している。いずれも単独で全対象国・全権利の結論にはならない。
