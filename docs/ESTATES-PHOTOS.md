# World Heritage photo credits

Verified 2026-11-03 using Wikimedia Commons imageinfo/extmetadata and linked file pages. All 22 property spaces have actual destination photographs. These are representative views of the named heritage places, not exhaustive depictions of the UNESCO boundaries.

## Reuse and display

- `public/estates/heritage-media.js` exports `HERITAGE_MEDIA` keyed by numeric board position. `src` is relative to the estates page.
- Display `credit`, the linked `license` / `licenseUrl`, and linked `source` with each photograph. Public-domain entries may omit a license URL, but retain source/credit.
- Local JPEGs are resized to at most 800 pixels and recompressed; original framing retained in the files. CSS may crop the displayed view. The `changes` field discloses this.
- Each resized photograph remains under the same license identified below, including ShareAlike and Free Art License obligations. These image licenses do not replace the license of unrelated game code.
- Wikimedia reuse reference: https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia
- No UNESCO website photographs were copied. Historical interior photograph for Ħal Saflieni is deliberately labeled as historical.
