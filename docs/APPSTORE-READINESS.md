# App Store出荷前レビュー — 世界遺産トラベル

確認日: 2026-11-04。対象はこのリポジトリの `public/estates/`。審査・法律上の承認書ではなく、コード／ブラウザ検証と一次資料による出荷判断メモです。

## 結論

**現状のApp Store申請は保留。遊べるWeb試作としては進んでいるが、商用品の出荷条件を満たしたとは言えない。** ゲームの購入・競売・建築・交渉、CPU1〜3人、通信の正常系は動いている。ただし、それはiOS実機品質・再接続・第三者権利・審査通過の証拠とは別。

## 今回修正したもの

- 対戦中の「退出する」に確認を追加。キャンセル可能で、CPUも確認中は進まない。通信退出は全員の対戦を止めることを明示。
- ブラウザが非表示になるとCPUタイマーを止め、戻ると再開。保存/復帰機能を実装したという意味ではない。
- 遊び方、通信・保存の制限、データ取扱い、公開サポートをゲーム内から参照可能に。外のページへ移動しなくても読める。
- 写真22点のクレジット・ライセンス・原典・使用画像への単独アクセスを一か所に整理。音がプログラム生成であることも説明。
- 写真3の指定クレジットを `A.Savin, Wikipedia` に修正。
- 非公式であり、現実の遺産所有/売買/建設許可を表さないことを表示。
- 古い「交渉未対応」のルール文書を修正。既存の交渉下書き保持・到着案内などの継続改善を維持。

これらはリスク低減・使いやすさ改善であり、下記権利やApp Store出荷の未解決事項を治癒したという主張ではない。

## 権利調査：事実と判断を分ける

### ゲームの方法、表現、ブランド

米国著作権局はゲームのアイデア・方法と、説明文章や美術の著作権を区別する。これは他国法、商標、外観などが無関係という意味ではない。[米著作権局](https://www.copyright.gov/register/tx-games.html)

HasbroはMONOPOLY名・ロゴに加え、特徴的盤面や四隅などを商標として表示している。[Hasbro公式資料](https://www.hasbro.com/common/assets/image/Printables/dad288661c4311ddbd0b0800200c9a66/3BA69B8250569047F513A43FE38BE736/3BB6FBBA50569047F53476FB46A7ECAE.pdf)

**コードからの評価:** 現行盤面の40マス・22物件・4交通・2公共施設・8色の組合せと経済数値が近い。地名変更、€への変更、免責文だけで安全とは判断できない。正方形そのものを禁止と断定せず、特徴の組合せ全体を対象国で確認する。ストア名・アイコン・キーワードに権利者の商品名を流用しない。現題名の登録商標クリアランスも未実施。

### 日本向け配布の確認範囲

文化庁もアイデアと創作的表現を区別し、特許庁・経産省は著作権以外に商標・周知表示等の保護を説明している。[文化庁](https://www.bunka.go.jp/seisaku/chosakuken/kaizoku/faq.html) [特許庁](https://www.jpo.go.jp/support/ipr/kenrishingai.html) [経産省](https://www.meti.go.jp/policy/economy/chizai/chiteki/unfaircompetition_new.html)

商品形態模倣の規制には期間・除外条件もあり、周知表示等の規制とは区別する。「古い作品だからすべて自由」「似ているから必ず違法」とは判断しない。本件について国内の登録商標の権利存続・指定商品/役務・類似範囲を原簿まで照合したわけではない。出荷する題名・図形と対象市場を確定し、[J-PlatPat](https://www.j-platpat.inpit.go.jp/t0100)等で現行の権利を調べる必要がある。[INPITの検索案内](https://faq.inpit.go.jp/FAQ/2024/03/000288.html)

### UNESCO・施設名

公式エンブレム/ロゴ利用には条件がある。現コードで公式ロゴの利用は見つからず、文字リンクで出典を示している。[UNESCOの案内](https://whc.unesco.org/en/emblem) [ロゴ使用FAQ](https://whc.unesco.org/en/faq/16)

同案内は歴史的決定も含む。地名を記述するすべての場合にUNESCO許可が要る、と一律には判断しない。施設ブランド・現地の条件、公式提携に見える説明、聖地に売買・ホテル建設を結びつける表現も検討する。

### CC BY-SA／FALとネイティブ配布

CC BY-SAは表示・変更説明・継承などを要求し、受領者の権利を制限する追加条件・技術的制限を禁じる。商標等は別。[CC BY-SA 4.0法文](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en)

FAL第4項には、作品へ独立してアクセスできなくなる組込みに関する条件がある。[FAL原文](https://artlibre.org/licence/lal/en/)

Apple標準EULAの制限とオープンソース例外を確認し、写真のライセンス・ネイティブバンドルの暗号化・取得経路・第三者素材の明示を別途評価する。[Apple標準EULA](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/)

単独画像へのリンクを追加したことだけで、将来の制限付きアプリ配布が必ず適法になるとは言わない。別許諾・自作素材・制約の異なる素材も候補。無許可で権利者へ連絡したり料金を払ったりしていない。
